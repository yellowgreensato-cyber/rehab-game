# 手のリハビリゲーム / Hand Rehab Game

脳卒中後遺症などで手のリハビリをがんばっている方が、
たのしみながらたくさん手を動かせるように作った、ブラウザで遊べるゲームです。

A browser game for people working on hand rehabilitation after a stroke.
Move your hand a lot — while having fun.

**▶ あそぶ / Play:** https://yellowgreensato-cyber.github.io/rehab-game/

---

## つかいかた / How to play

1. コースをえらぶ（リーチ／はこぶ／なぞる／じゅんばん／エアホッケー）
2. おおきさをえらぶ（イージー／ノーマル／ハード／たつじん）
3. 時間をえらぶ（30秒／45秒／60秒）
4. スタート

- **リーチ** … 指がほとんど動かせない方へ。的に触れるだけで反応します（クリック不要）
- **はこぶ** … 人差し指のドラッグ練習に
- **なぞる** … 指先のコントロール練習に
- **じゅんばん** … 注意・探索の練習に
- **エアホッケー** … 下があなた、上がパソコン。右手でも左手でも条件は同じ。
  ボールの大きさと速さが3段階。時間ではなく、先に 7／14／21 点をとったほうが勝ちです

15個に1個は「スケルトンの的」（見えない的）で、当たると3ポイントです。

## 特長 / Features

- インストール不要。HTMLファイル1つだけ
- パソコン・タブレット（iPad / Android）・スマホのどれでも動きます
- 日本語 / English 切り替え
- 遊んだ記録はブラウザのなかだけに保存されます（個人を特定する情報は集めていません）
- アクセス数のみ、クッキーを使わない方法で集計しています

## ダウンロードしてカスタマイズ / Download & customize

`index.html` をダウンロードして、AI（ChatGPT・Claude など）に渡してください。
「もっと的を大きくして」「音を変えて」「言葉を追加して」など、
自分にぴったりのゲームに作りかえてもらえます。

Download `index.html` and hand it to an AI assistant.
Ask for bigger targets, different sounds, your own words of encouragement —
whatever fits you best. It is a single self-contained file, so it is easy to edit.

## ご注意 / Note

医療機器ではありません。リハビリの補助としてお使いください。
体調に不安があるときは、主治医や担当のセラピストにご相談ください。

This is not a medical device. Please use it as a supplement to your rehabilitation,
and consult your doctor or therapist if you have any concerns.
